成为 SORDEX 做市商

非托管、零审核、即时开通。用自己的资金地址签名领取 API Key，自建策略对接订单簿。

非托管

资金始终锁在你自己的做市金库或钱包授权额度内，平台零提现权，撤回随时。

maker 费率 0

认证做市商挂单免协议费，只有吃单按普通费率。盘口越好，激励越高。

零审核即时开通

资金地址签名即时领取 API Key，无需等待人工审核。随时自助轮换、更新 IP。

自建策略

用 API 提交你自己的签名报价，完全掌控价格与节奏；也可用平台公开自动做市规则一键托管。

接入流程

  1. 1
    准备资金资金放在 EOA 钱包，或放在合约金库 / 多签（无私钥）。
  2. 2
    签名领取 KeyEOA 直接本地址签名；合约金库先 setAgent 授权一个签名地址，再用该地址代签。
  3. 3
    配置 IP 白名单填入你的做市程序出口 IP 或网段，只有白名单内的 IP 能用这把 Key 报价。
  4. 4
    对接 API 报价请求头带 x-mm-key 提交签名报价。接口文档见 API 页。
